# Ajouter des pistes

Une piste est un onglet d'information affiché dans le visualiseur de hit lorsqu'un dossier correspond. Ouvrez l'onglet **Pistes** et utilisez le bouton d'ajout pour en créer une. L'ordre des onglets de piste suit leur ordre dans l'éditeur de dossier.

`dossier_lead`

## Détails requis pour une piste

Chaque piste a besoin d'étiquettes anglaise et française, d'un identifiant d'icône Iconify valide, d'un format et d'un contenu. Les étiquettes localisées sont celles que les utilisateurs voient dans la langue choisie pour leur interface. Utilisez le navigateur Iconify accessible depuis l'éditeur pour sélectionner une icône qui existe.

Le format intégré **markdown** rend le contenu dans le visualiseur de hit. Il convient aux étapes d'enquête concises, au contexte et aux références. Les pistes Markdown sont rendues avec le hit actuel comme contexte; vérifiez donc tout contenu dynamique sur un hit réel correspondant avant de le publier.

## Formats de piste des plugins

Les plugins installés peuvent enregistrer d'autres formats de piste. Lorsqu'un tel format est choisi, son éditeur propre s'affiche et peut enregistrer des métadonnées propres au format. Le format doit être disponible dans le déploiement Howler actuel pour que la piste soit rendue; sinon, le visualiseur de hit signale une piste invalide.

Le changement de format d'une piste efface son contenu et ses métadonnées actuels. Terminez la configuration du nouveau format avant d'enregistrer et supprimez les pistes inutilisées à l'aide du contrôle de suppression.
