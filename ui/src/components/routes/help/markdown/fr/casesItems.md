# Éléments de cas

Les éléments de cas sont affichés dans la barre latérale et leur icône indique leur type. Sélectionnez un résultat ou un événement pour ouvrir ses détails, un élément Markdown pour lire sa note, ou un cas lié pour ouvrir son tableau de bord. Les références ouvrent leur URL dans un nouvel onglet.

## Utiliser et gérer les éléments

Utilisez **Ajouter un élément** dans la barre latérale pour créer une référence ou une note Markdown. Une référence requiert un titre et une URL. Un élément Markdown requiert un titre et du contenu; son ouverture fournit un éditeur avec les commandes Enregistrer et Annuler. Placez l'un ou l'autre à la racine du cas ou dans un dossier.

`case_item_types`

## Comportement des éléments

- Les **hits et événements** ouvrent les détails de l'enregistrement dans l'espace de travail du cas.
- Les **notes Markdown** ouvrent un document rendu qui peut être modifié.
- Les **références** ouvrent leur URL externe dans un nouvel onglet.
- Les **cas connexes** ouvrent le tableau de bord du cas lié et peuvent être développés dans l'arborescence.
- Les **dossiers** organisent les autres types d'éléments.

Cliquez avec le bouton droit sur un élément navigable pour ouvrir sa page autonome dans un nouvel onglet. Utilisez le même menu pour le renommer ou le supprimer.
