# Structure des dossiers

Les dossiers regroupent les éléments associés à un cas. Utilisez la commande d'ajout de dossier dans la barre latérale pour en créer un, puis glissez-y les éléments. Déposer un élément dans la zone de dépôt racine le replace à la racine du cas.

## Organiser l'enquête

Les dossiers peuvent être imbriqués pour représenter les volets d'une enquête. Développez-les ou réduisez-les avec le chevron et utilisez leur menu contextuel pour gérer le dossier et son contenu. Un dossier peut contenir des dossiers, des éléments de preuve, des notes et des références; seuls les dossiers peuvent être parents d'éléments.

## Déplacer, renommer et supprimer

Glissez un élément sur un dossier pour le déplacer, ou utilisez la zone de dépôt racine pour retirer son parent. Les noms d'éléments doivent être uniques parmi les éléments frères; renommez donc un élément avant de le déplacer si sa destination contient déjà le même nom.

Cliquez avec le bouton droit sur un dossier ou un élément pour le renommer ou le supprimer. La suppression d'un dossier supprime aussi son contenu : examinez donc son arborescence avant de confirmer. Les cas liés demeurent toujours à la racine du cas et ne peuvent pas être placés dans un dossier.
