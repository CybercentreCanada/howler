# Manage and use dossiers

The Dossier Manager searches titles, queries, and owners. Each card identifies its scope and owner, lists its leads and pivots, and provides an **Open in Search** shortcut for reviewing the configured query.

Select a card to edit it. Lead and pivot chips on a card take you directly to the corresponding editor tab, which is useful when maintaining a large dossier. Query-string tab state is preserved in the URL, so a copied editor link can point a teammate to the relevant configuration section.

## Publish safely

Before saving a new or changed dossier, verify all of the following:

1. The query returns only the intended hits.
2. Each label is complete in English and French.
3. Icons, formats, content, and pivot mappings are valid.
4. Links and dynamic Markdown render correctly for a representative hit.
5. The visibility scope is appropriate for the content.

Deleting a dossier removes its reusable leads and pivots from future matching hits. It does not delete the hits themselves or alter existing cases. Use the confirmation dialog carefully, especially for global dossiers that support a shared workflow.
