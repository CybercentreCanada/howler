# Case items

Case items are the entries shown in the sidebar. Their icon identifies their type. Select a hit or event to open its details, select a Markdown item to read its note, and select a linked case to open its dashboard. Reference items open their URL in a new tab.

## Use and manage items

Use **Add item** in the sidebar to create a reference or a Markdown note. A reference needs a title and URL. A Markdown item needs a title and content; opening it provides an editor with Save and Cancel controls. Place either at the case root or in a folder.

`case_item_types`

## Item behavior

- **Hits and events** open their record details inside the case workspace.
- **Markdown notes** open an editable rendered document.
- **References** open their external URL in a new tab.
- **Related cases** open the linked case dashboard and can be expanded in the tree.
- **Folders** organize the other item types.

Right-click a navigable item to open its standalone page in a new tab. Use the same menu to rename or remove it.
