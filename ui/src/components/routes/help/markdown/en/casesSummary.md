# Case summary

A case title and summary identify the investigation at a glance. The summary appears below the title on the dashboard, while the overview is a longer Markdown document that can be edited directly from the dashboard.

## Use the dashboard

The dashboard displays the case title, summary, and editable Markdown overview. Use the edit control beside the overview to save a narrative, handoff notes, or a resolution summary.

It also groups evidence into threat, target, and indicator summaries, shows the investigation duration, and provides task, alert, and related-case panels. Aggregate values come from the hit and event evidence currently in the case, so they update as evidence is added or removed.

`case_dashboard`

## Track tasks and related work

Add a task from the dashboard, write its summary, optionally link it to a case item, and assign it to a user. Check the task when it is complete. Linked child cases can contribute read-only task lists to the parent dashboard; use the child-case filter or visibility toggle to focus the list.

The Alerts panel opens a case-scoped view of a hit. The Related Cases panel opens the linked case. Both panels paginate their entries so a case can hold more evidence than is visible at once.
