# Generate UI TypeScript entity types from a live seeded API

Frontend entity interfaces in `ui/src/models/entities/generated/` are generated by querying a running, seeded Flask API (`api/build_scripts/generate_classes.py`) rather than from static schema files or an offline OpenAPI spec. Because Clue integration and backend plugins extend entity schemas at runtime when the application boots, inspecting the live server guarantees the generated TypeScript types match the active runtime shape.

## Considered Options

- **Static OpenAPI/schema-only codegen**: Rejected because plugin and feature-flag schema extensions were applied dynamically at application startup.

## Consequences

- Regenerating UI entity types requires running a local API instance with seeded randomized data, and generated files under `ui/src/models/entities/generated/` must never be edited by hand.
