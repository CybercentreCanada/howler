### Howler MCP Server

This project introduces an MCP server that allows AI agents to interact safely with Howler on behalf of a user.

At a high level, it enables teams to:

- ask an AI assistant to retrieve and review alerts,
- generate structured investigation summaries,
- and take lightweight actions (like adding comments) directly in the analyst workflow.

In short, it brings Howler into AI-assisted workflows so analysts can get faster context and spend more time on decisions rather than navigation.
